# AndroScope Frontend

This directory contains the React-based frontend for AndroScope.

## Tech Stack

- **Framework:** React with Vite
- **Language:** TypeScript
- **UI:** Material-UI
- **Charting:** Recharts
- **Real-time Communication:** WebSockets

## Setup and Running

1.  **Prerequisites:** Ensure you have Node.js (v18+) and an Android emulator with ADB installed and running.
2.  **Navigate to this directory:**
    ```bash
    cd androscope-frontend
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Run the development server:**
    ```bash
    npm run dev
    ```
The application will be available at `http://localhost:5173`.
